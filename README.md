
# Controle de Níveis de Água

Projeto desenvolvido em Python para simular o monitoramento
de um reservatório de água pelo terminal.

## Funcionalidades

- Representação dos cinco níveis de água em uma lista.
- Mensagens de alerta com cores usando Colorama.
- Função para definir a cor conforme o nível.
- Simulação automática dos níveis do reservatório.
- Restauração do estilo do terminal após as mensagens.

## Tecnologias utilizadas

- Python
- Colorama

## Como executar

Instale a biblioteca:

```bash
python -m pip install colorama
```

Execute o programa:

```bash
python main.py
```
